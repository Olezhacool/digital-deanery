## 04.11.2026 — Этап 0. Инфраструктура и бриф

**Инструмент:** OpenCode (desktop), модель DeepSeek V4.1 Flash Free.
**Роль ассистента:** постановщик инфраструктуры, аналитик задания.

### 1. Создание «сферы» проекта

**Промпт пользователя (дословно):**
> нам нужно с тобой созать изначально сферу, где все это будет, а точнее, гит хаб, там нужно будет создать репозиторий у меня еще 2е подопечных

**Что сделал ассистент:**
- Проверил окружение: `git 2.52.0` есть, `gh` (GitHub CLI) отсутствует.
- Установил GitHub CLI через `winget install --id GitHub.cli`.
- Запустил `gh auth login --web`, выдал одноразовый код для привязки аккаунта.
- Создал публичный репозиторий `digital-deanery`, склонировал локально.
- Заложил фундамент: `README.md`, `docs/roadmap.md`, `.gitignore`, `.gitattributes`, `.editorconfig`, первый коммит и пуш.

**Проблемы и как решались:**
- `gh` не в PATH после установки → в каждом вызове оболочки PATH перечитывается из реестра.
- GitHub отдал `HTTP 500` на странице `/login/device` и `HTTP 502/500` на `POST /user/repos`. Проверил `githubstatus.com` — «All Systems Operational», то есть ошибки транзиентные. Повторный запрос прошёл, но вернул `422 name already exists` — репозиторий фактически создался с первого «неудачного» запроса. Вывод: при 5xx от GitHub нельзя слепо повторять создание, сначала проверять `gh repo view`.

### 2. Разбор конкурсного задания

**Промпт пользователя (дословно):**

**Что сделал ассистент:**
- Разобрал ТЗ на: суть, сроки, обязательное ядро, требования, состав сдачи.
- Отдельно развернул все 4 критерия оценки: что проверяют, как набрать баллы, что убивает баллы.
- Результат — `docs/brief.md`.
- Из критерия №2 сделал вывод: нужен этот журнал и файлы-инструкции для агентов (`AGENTS.md`).

**Наблюдение:** самое ценное в ТЗ — фраза «покажи, каким деканат может стать, а не только каким он бывает сейчас». Она задаёт планку: копия сайта вуза баллов не даст.
