# Дизайн-система «Цифрового деканата» — инструкция для ИИ-агента

Ты — продуктовый дизайнер и фронтенд-разработчик. Собери интерфейс личного кабинета студента строго по этой системе. Mobile-first, ширина 360–430 px, светлая и тёмная темы. Ничего не добавляй «от себя» в палитру, радиусы и типографику — только описанные токены.

## 1. Характер

Современное студенческое приложение, а не сайт вуза. Дружелюбный тон, крупные заголовки, много воздуха, скруглённые карточки, один яркий «герой» на экран. Ощущение: быстро, понятно, приятно.

Правила тона:
- Заголовки — с заглавной буквы, обычный регистр, без КАПСА (КАПС только для мелких меток секций).
- Обращение к студенту — на «ты», живо и коротко: «Далее: матанализ · через 41 мин», «В этот день пар нет — можно выдохнуть».
- Никакого канцелярита: не «осуществить подачу заявления», а «Заказать справку».
- Числа и факты — крупно, текст-пояснение — мелко и приглушённо.

Радиусы: карточки **30–32 px**, плитки **30 px**, иконки-квадраты **20 px**, чипы/кнопки/сегменты — **999 px** (пилюля), мелкие бейджи **12 px**, аватары — круг.

Тени — только у трёх вещей: активный сегмент (`0 6px 16px #0003`), герой-карточка (цветная тень в тон градиента `0 14px 30px #EC406240`), плавающая навигация (`0 10px 40px #0002`). Всё остальное — плоско, разделение цветом фона.

## 3. Типографика

Один гротеск: **Inter** (fallback Roboto, system-ui). Кириллица обязательна.

| Элемент | Размер / вес |
|---|---|
| Заголовок экрана `h1` | 40 px / 800, letter-spacing −1 px, line-height 1.05 |
| Подзаголовок под h1 | 16–17 px / 600 + цветная точка 10 px слева |
| Заголовок блока `h2` | 26 px / 800, letter-spacing −0.5 px |
| Название в карточке | 20–23 px / 700 |
| Основной текст | 18–19 px / 400 |
| Описание, подпись | 16–17 px / 400, цвет muted |
| Метка секции | 14 px / 700, letter-spacing 1 px, UPPERCASE, muted |
| Крупная цифра (средний балл, дни) | 56–64 px / 800 |

Точка статуса: синяя — нейтрально, зелёная с ореолом `0 0 0 4px #22C55E33` — «онлайн / всё хорошо», красная — срочно.

## 4. Каркас экрана

1. Отступы по бокам **20 px**, сверху 20 px (плюс `env(safe-area-inset-top)`).
2. Первый экран: `h1` → подзаголовок с точкой → контент.
3. Контент — вертикальный поток, между блоками 12–16 px.
4. **Плавающая нижняя навигация**: пилюля `backdrop-filter: blur(16px)`, отступ 14 px от низа + safe-area, 5 пунктов. Иконка 30 px (линейная, stroke 1.8) + подпись 14 px / 600. Активный пункт — тёмная «таблетка» с инверсным цветом.
5. Контенту обязателен нижний padding **≥120 px**, чтобы навигация ничего не перекрывала.
6. Максимальная ширина контента 520 px, центрируется на десктопе.

## 5. Компоненты

**Сегмент-переключатель.** Контейнер-пилюля цвета карточки, padding 6 px; активный пункт — чёрная пилюля с белым текстом и тенью. Высота пункта ≥ 48 px.

**Чипы-фильтры.** Горизонтальный скролл без скроллбара, белые пилюли, активная — чёрная. Отступы 13×22 px.

**Герой-карточка.** Градиент 135°, радиус 32 px, padding 22 px, белый текст, цветная тень. Внутри: плашка-статус (полупрозрачная белая пилюля), заголовок 30 px / 800, строка «🗓 дата · 📍 место», внизу — ряд с крупной цифрой и белой пилюлей-кнопкой.

**Карточка списка.** Фон `card`, радиус 30 px, padding 20 px. Слева — белый квадрат 66×66 (радиус 20) с числом 30 px и красным месяцем 15 px; справа название 20 px / 700 и подпись muted; справа шеврон `›` 24 px muted.

**Карточка пары.** Слева колонка 62 px: начало 23 px / 700, конец 19 px muted, «1 ПАРА» 13 px / 700. Вертикальная синяя линия 4 px. Справа: название 23 px / 700, бейдж типа занятия (светло-синий фон `soft`, синий текст, радиус 12), «· аудитория» muted, преподаватель muted.

**Выбор дня.** 6 равных пилюль (Пн–Сб), день недели 15 px, число 26 px. Активный — чёрный.

**Плитка раздела.** Сетка 2 колонки, карточка минимум 200 px высотой. Цветной квадрат-иконка 62×62 (радиус 20, белая иконка), заголовок 21 px / 700, описание 17 px muted.

**Статистика.** Сетка 3 колонки, карточка-плашка: подпись muted 16 px, значение 26 px / 800.

**Строка оценки.** Название дисциплины 20 px / 700, преподаватель muted 16 px; справа крупная оценка 26 px / 800; под названием — ряд бейджей по видам работ (Экзамен, Зачёт, Контрольная).

**Статус заявки.** Пилюля: «Новая» — `soft`/primary, «В работе» — `#FEF3C7`/`#B45309`, «Готова» — `#DCFCE7`/`#15803D`, «Отклонена» — `#FEE2E2`/`#B91C1C`.

**Поля ввода.** Фон `card`, радиус 18 px, padding 16 px, без рамки; фокус — линия 2 px primary снизу.

**Шторка (bottom sheet).** Затемнение `#0008`, панель снизу, радиус 30 px сверху, padding 22 px 20 px + safe-area, максимум 80 vh со скроллом. Кнопки внизу — пилюли.

**Чат ассистента.** Полноэкранный слой: шапка с названием и кнопкой «Закрыть», лента сообщений, поле ввода снизу. Сообщение пользователя — синяя пилюля справа, ответ — карточка слева. Под полем — 2–3 чипа-подсказки.

**Скелетон загрузки.** Плашки цвета `card` с мягким пульсирующим градиентом, повторяют форму реального контента. Никаких спиннеров на весь экран.

**Пустое состояние.** Карточка с иконкой, коротким заголовком и подсказкой, что делать: «Пока нет заявок — закажите первую».

## 6. Принципы

- Крупно, воздушно, тап-зоны ≥ 48 px.
- Цвет несёт смысл: синий — действие и ссылка, красный — дата и срочное, зелёный — успех и онлайн, оранжевый — в работе, золото — только награды.
- **Один герой на экран** (градиентная карточка или баннер), остальное спокойное.
- Анимации — только в ответ на действие (переключение вкладки, нажатие). Никаких каскадных появлений.
- Тёмная тема — не инверсия, а свои значения токенов.
- Доступность: контраст ≥ 4.5:1, `aria-label` у иконочных кнопок, `:focus-visible` с обводкой 2 px primary.

## 7. Экраны кабинета

1. **Вход** — заголовок, поля логина и пароля, кнопка, блок демо-доступа, дисклеймер.
2. **Главная** — приветствие, следующая пара героем, пары на сегодня, дедлайны, объявления, быстрые действия.
3. **Расписание** — неделя и чётность, переключатель недель, дни Пн–Сб, карточки пар, сессия.
4. **Успеваемость** — средний балл крупно, прогресс, дисциплины с оценками, долги, сессия.
5. **Заявки** — список со статусами, кнопка «Новая заявка», шторка создания, детали с историей.
6. **Профиль** — аватар-буква, ФИО, факультет, направление, курс, группа, настройки, выход, дисклеймер.
7. **Ассистент** — полноэкранный чат поверх любого экрана.

## 8. Технически

- Один HTML-файл или React + Tailwind. Сборка не обязательна.
- Цвета — только через CSS-переменные, тема переключается атрибутом `data-theme`.
- `viewport-fit=cover` + `env(safe-area-inset-*)`.
- Иконки — инлайн SVG, stroke 1.8, без внешних библиотек.
- Все данные экранировать при вставке в HTML.
- Никаких секретов и ключей во фронтенде.
