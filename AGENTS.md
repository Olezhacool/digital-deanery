# AGENTS.md — правила для ИИ-агентов

Этот файл читают все ИИ-ассистенты и субагенты, работающие над проектом.
Читать целиком перед первой правкой кода.

## Что за проект

«Цифровой деканат будущего» — работающий прототип личного кабинета студента для конкурса.
Полное ТЗ и разбор критериев — в `docs/brief.md`. План — в `docs/roadmap.md`.
Журнал работы с ИИ — в `docs/ai-log.md` (заполнять обязательно).

## Стек

- **Python 3.13 + aiohttp** — один процесс отдаёт и API, и приложение.
- **SQLite (aiosqlite)** — реальное хранение данных; при росте меняется на PostgreSQL.
- **Один HTML-файл без сборки** — быстрый старт, простой деплой, нечего ломать.
- Пароли — PBKDF2-SHA256, сессии — подписанная HMAC-cookie.

Причина смены: референс, который показал заказчик, построен на этой же схеме — она проверена и даёт рабочий прототип без сборки. Next.js отклонён как лишний слой для конкурсного MVP. Подробнее — `docs/ai-log.md`, запись от 07.11.2026.

Стек не менять без записи в `docs/ai-log.md` и причины.


## Жёсткие правила (из ТЗ — нарушение = потеря баллов)

1. **Только вымышленные данные.** Никаких реальных ФИО, оценок, номеров зачёток, телефонов, почт.
2. **Чужое не открывается.** Каждый запрос к данным проверяет владельца **на сервере**. Подстановка чужого ID в URL → 404, а не данные.
3. **Пароли только хешем.** Никаких `password` в открытом виде ни в БД, ни в логах.
4. **Секреты только в `.env`.** Ключи API не попадают в клиентский бандл и в репозиторий.
5. **Мобильная версия от 360 px.** Каждый новый экран проверять на этой ширине.
6. **Дисклеймер.** В футере и на экране входа: «Концепт для конкурса, не официальный сервис вуза».
7. **Без логотипа вуза.** Только собственный знак.
8. **Лицензии.** Шрифты и иконки — OFL/MIT/Apache. Не тащить картинки из интернета без лицензии.

- Шрифты: **Manrope** (заголовки), **Inter** (текст). Оба — OFL, кириллица есть.
- Радиусы: 12 px для карточек, 16 px для модалок, 999 px для пилюль.
- Сетка отступов: 4 / 8 / 12 / 16 / 24 / 32 / 48.
- Тач-цели не меньше 44×44 px.
- Нижняя навигация на мобильном, боковая — на десктопе.
- Тёмная тема — опционально, но если делать, то на всех экранах сразу.

## Правила кода

- TypeScript strict, без `any` без причины.
- Server Components по умолчанию; `"use client"` — только где нужна интерактивность.
- Валидация входных данных — `zod` на сервере.
- Никаких `fetch` к внешним API из клиента, если там секрет.
- Компоненты — в `src/components`, имя файла = имя компонента в PascalCase.
- Тексты интерфейса — по-русски, без канцелярита.

## Как работать

1. Сначала прочитать `docs/brief.md` и этот файл.
2. Перед крупной фичей — короткая спека в `docs/`, потом код.
3. Проверять результат: `npm run build`, `npm run lint`, ручной проход сценария.
4. Ошибки ИИ не скрывать — записывать в `docs/ai-log.md` вместе с исправлением.
5. Не удалять чужие файлы и не переписывать чужой код без необходимости.
