# Цифровой деканат будущего

Личный кабинет студента, который заменяет очередь в деканат: расписание, оценки, задания, справки — всё в одном месте, с AI-помощником.

> Статус: **проектирование**. Код появится после согласования стека и объёма MVP.

---

## Зачем это

Студент тратит время на то, чтобы узнать то, что уже где-то записано: «когда пересдача?», «сколько я должен?», «что сдать на этой неделе?». Деканат тратит время на те же вопросы, заданные голосом.

Цифровой деканат убирает посредника: данные лежат в одном месте, доступны в любой момент, а рутинные вопросы закрывает ассистент.

## Кто пользуется

| Роль | Что делает |
|---|---|
| **Студент** | Смотрит расписание, оценки, задания, заказывает справки |
| **Преподаватель** | Выставляет оценки, публикует задания и материалы |
| **Деканат** | Ведёт дисциплины, группы, сессии, отвечает на заявки |

Роли вводятся по мере роста проекта — MVP начинается со студента.

## Разделы

- [ ] Расписание занятий — неделя, текущая пара, изменения
- [ ] Оценки и зачётка — ведомость, средний балл, сессия
- [ ] Задания и дедлайны — список работ, сдача, статусы
- [ ] Посещаемость — отметки, пропуски, уважительные причины
- [ ] Справки и документы — заказ, статус, готовые файлы
- [ ] Оплата обучения — начисления, задолженности, квитанции
- [ ] Уведомления — изменения в расписании, новые оценки, дедлайны
- [ ] AI-ассистент — «когда моя следующая пара?», «что сдать на этой неделе»

## Стек

Предлагается **Next.js + TypeScript + Tailwind CSS**, база — **PostgreSQL** (Prisma).
Причины: один язык на фронте и бэке, готовый роутинг и авторизация, бесплатный деплой на Vercel.

Стек не зафиксирован — обсуждается в issue.
