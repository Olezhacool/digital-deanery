# Цифровой деканат будущего

Рабочий прототип личного кабинета студента: расписание, успеваемость, заявки и справки, объявления и AI-ассистент — в одном месте. Концепт для конкурса, не официальный сервис вуза.

## Демо-доступ

| Логин | Пароль | Кто |
|---|---|---|
| `anna` | `anna2026` | Иванова Анна, ИТ-2-1, 2 курс |
| `maxim` | `maxim2026` | Петров Максим, ЭК-1-2, 1 курс |

Данные у аккаунтов разные: видно, что кабинет показывает только своё.

## Что умеет

- **Вход и профиль** — логин и пароль, сессия в httpOnly-cookie; ФИО, факультет, направление, курс, группа, зачётка.
- **Расписание** — неделя с чётностью, дни Пн–Сб, аудитория и преподаватель, сессия.
- **Успеваемость** — оценки по дисциплинам, средний балл, кредиты, долги, экзамены.
- **Заявки и справки** — создание заявки, статус, история; справка «в работе» и «готова».
- **Уведомления** — объявления деканата на главной.
- **Ассистент** — отвечает по данным студента: «что сдать на этой неделе», «когда следующая пара», «как дела с учёбой».
- **Поиск по кабинету** — пока не реализован (в планах).

Мобильная вёрстка — от 360 px. Светлая и тёмная темы.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env          # Linux/macOS: cp .env.example .env
```

В `.env` обязательно задайте случайный `SECRET`:

```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

Затем:

```bash
python -m server.main
```

Кабинет — http://localhost:8080. При первом запуске база создаётся и заполняется демо-данными.

## Как устроено

```

  roadmap.md            план развития
  ai-log.md             журнал работы с ИИ
```

### Безопасность

- Пароли хранятся как PBKDF2-SHA256, 150 000 итераций, своя соль у каждого.
- Сессия — подписанная HMAC cookie, `httpOnly`, `SameSite=Lax`, срок 7 дней.
- Каждый запрос к данным проверяет владельца на сервере: чужая заявка по прямому ID отдаёт 404.
- Секреты — только в `.env`, в репозиторий не попадают.
- Все данные вымышленные.

### Ограничения прототипа

- SQLite вместо PostgreSQL — для демо достаточно, при росте нагрузки меняется за один слой.
- Ассистент работает по правилам, без внешней LLM: не нужен ключ и нет риска утечки.
- CSRF-защита опирается на `SameSite=Lax` и JSON-only API; для продакшена стоит добавить токен.
